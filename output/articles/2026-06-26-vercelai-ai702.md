## How it works

The Vercel AI SDK operates through a layered architecture. At the top level, developers interact with friendly JavaScript/TypeScript APIs that handle model selection, prompt construction, and response streaming. Below that sits a set of provider-specific integrations and configuration layers. The gateway component sits at a critical juncture—it's responsible for standardizing requests and responses between the application layer and the actual AI service providers.

By centralizing gateway logic, Vercel can make improvements to how requests are routed, how errors are handled, and how model responses are processed without requiring developers to change their application code.
