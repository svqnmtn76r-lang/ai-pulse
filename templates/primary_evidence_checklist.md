# 一次情報（実測）受け皿 & チェックリスト

> 目的: 比較記事を「テンプレ流用」から「独自の一次情報を持つ記事」へ引き上げる。
> Cowork は実測できない（音声録音・速度実測・スクショ撮影は HUMAN-ONLY / Hiro の実機作業）。
> 各記事冒頭の `<!-- EDITORIAL TODO ... -->` に対応する実測を、下の受け皿に流し込んでから公開する。
> 実測を入れた箇所には 🟢（実測）ラベルを付ける。未実測のまま公開しない。

記事に貼る受け皿の形（HTMLコメントを外し、実値・画像に置換）:

```markdown
## Hands-on notes (tested 2026-06-__)
- Setup time: __
- What we measured: __
- Result: __
![screenshot caption](/images/<article-slug>/<shot>.png)
> Our take: __（1〜2文の独自所感）
```

## カテゴリ別 実測チェックリスト

### AI音声（ElevenLabs vs Murf）
- [ ] 同一スクリプト（60〜90秒）を両ツールで生成し、音声ファイルを保存（記事に埋め込み or リンク）
- [ ] 自然さ・感情表現・発音の癖・不自然な間を3点以上コメント
- [ ] 各エディタUIのスクショ1枚ずつ
- [ ] ボイスクローン: ElevenLabs で1分音声からの即時クローンを試した所感（Murfは不可の旨）
- [ ] 多言語: 1言語で実出力して品質メモ

### マネージドWordPress（Kinsta vs WP Engine）
- [ ] 同一WPサイトを両ホストに設置（または両トライアル）
- [ ] TTFB / LCP を実測（WebPageTest等）。計測条件（地域・回線）を明記
- [ ] 各ダッシュボード（MyKinsta / WP Engine portal）のスクショ
- [ ] サポートに1問い合わせし、応答時間と質をメモ
- [ ] バックアップ/ステージングの操作感を1〜2文

### SEOツール（Semrush vs Ahrefs）
- [ ] 同一シードキーワード1語を両ツールで検索 → 難易度/ボリュームの差をスクショ比較
- [ ] 同一ドメインの被リンク数/鮮度を比較（スクショ）
- [ ] AI検索可視化（Semrush）と Brand Radar（Ahrefs）の画面を1枚ずつ
- [ ] レポート出力やUIの使い勝手を1〜2文

### EC（Shopify vs WooCommerce）
- [ ] 両方でテストストアを作り、公開までの所要時間を記録
- [ ] 実際の月額内訳表（Shopify: プラン+アプリ / Woo: ホスティング+拡張）を作成
- [ ] チェックアウト画面・管理画面のスクショ
- [ ] つまずいた点を具体的に2〜3点

### AIライティング（Jasper vs Copy.ai）
- [ ] 同一ブリーフ（広告1本＋800語ブログ）を両ツールで生成し、出力を並置
- [ ] 編集に要した手直し量（時間 or 修正箇所数）を記録
- [ ] ブランドボイス再現度を1〜2文
- [ ] Copy.ai は GTM/ワークフロー寄りである点を実画面で確認
