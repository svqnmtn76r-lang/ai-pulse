# Vercel AI SDK Now Supports Cartesia's Advanced Speech Generation and Transcription

Vercel has expanded its popular AI SDK with native support for Cartesia, a speech AI platform offering multiple capabilities for voice applications. The latest patch release (v7.0.22) integrates three distinct Cartesia services: Sonic 3.5 for speech generation, Ink-Whisper for batch transcription, and Ink 2 for real-time voice processing. This addition reflects the growing demand for multi-modal AI applications that seamlessly blend text and voice interactions.

## TL;DR

- **Cartesia integration**: The Vercel AI SDK now includes built-in support for Cartesia's speech platform, eliminating the need for custom wrapper implementations
- **Three new capabilities**: Sonic 3.5 speech generation, Ink-Whisper batch transcription, and Ink 2 real-time transcription are now available to developers
- **Impact**: Teams building voice applications can now integrate advanced speech AI directly into their Node.js and JavaScript applications without managing separate API integrations

## Background

The Vercel AI SDK has established itself as a comprehensive toolset for developers building AI applications. Since its inception, it has focused on reducing friction in AI development by providing unified interfaces across multiple AI providers. As language models became commoditized, the industry shifted toward multi-modal applications combining text, images, and increasingly, voice.

Speech integration has historically required developers to manage separate SDKs and API calls. A developer building a voice assistant, for instance, would need to juggle different libraries for speech-to-text transcription, text-to-speech generation, and potentially real-time voice processing. The Vercel AI SDK's philosophy of unified provider support extends naturally to addressing this fragmentation.

Cartesia represents a particularly interesting addition to the SDK's ecosystem. While companies like OpenAI and Google offer speech capabilities, Cartesia focuses specifically on voice with specialized models for different use cases—generation, batch processing, and real-time interaction each have tailored solutions rather than one-size-fits-all approaches.

## How it works

### Speech Generation with Sonic 3.5

Sonic 3.5 is Cartesia's latest text-to-speech model. Through the Vercel SDK, developers can now generate natural-sounding speech directly from text without writing custom HTTP clients. This matters for applications requiring voice output—podcast generators, accessibility features, voice notification systems, or interactive voice applications.

The integration means developers can instantiate a Cartesia provider, pass text content, and receive audio output through the standard SDK interface. This consistency is valuable because it allows teams already familiar with Vercel's other provider integrations (OpenAI, Claude, etc.) to work with speech generation using the same mental model and code patterns.

### Batch Transcription with Ink-Whisper

Ink-Whisper targets scenarios where transcription happens asynchronously—processing recorded audio files, analyzing uploaded voice messages, or handling large volumes of audio content where real-time response isn't required. The batch approach typically offers cost advantages and can handle larger files than real-time systems.

For developers, the SDK integration simplifies the workflow. Instead of managing separate transcription service credentials, implementing polling logic for batch job completion, or handling audio file uploads through different protocols, they can use Vercel's unified interface. This is particularly valuable for companies building customer service platforms, meeting transcription services, or voice note applications.

### Real-Time Transcription with Ink 2

Ink 2 represents the most technically demanding addition—real-time speech-to-text processing. This capability enables applications like live call transcription, real-time meeting assistants, or interactive voice interfaces that need immediate understanding of what users are saying.

Real-time transcription introduces unique challenges: latency sensitivity, streaming protocol management, and error handling for partial results. The Vercel SDK's integration abstracts these complexities, allowing developers to focus on application logic rather than low-level streaming implementation.

## Technical Integration Details

The patch implements these three Cartesia services as provider modules within the Vercel AI SDK architecture. This follows the established pattern where providers implement standard interfaces for initialization, parameter passing, and response handling. Developers building applications with these features can leverage existing Vercel patterns like function calling, streaming responses, and error boundaries.

The integration is backward compatible—existing applications using the SDK continue working unchanged. Teams can selectively adopt Cartesia support by importing the provider and configuring credentials, much like they would with any other provider.
