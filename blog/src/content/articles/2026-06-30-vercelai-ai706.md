## Background

The Vercel AI SDK has evolved significantly as developers discovered multiple patterns for implementing agentic loops—where AI models can call external tools, receive results, and decide on next steps. Early versions of the SDK supported several callback signatures for handling tool calls, allowing developers flexibility in how they structured their agent implementations.

As the library matured, the team standardized on preferred patterns while deprecating older callback aliases. However, many production applications still use these legacy patterns, and removing support entirely would force disruptive migrations. This creates a common challenge in API design: maintaining forward progress while respecting existing implementations.

The ToolLoopAgent is a core abstraction in the SDK for building agents that repeatedly interact with tools. Previous versions of the library accepted these deprecated callbacks at runtime but didn't provide complete TypeScript type information for them, creating a gap between what the code could actually do and what the type system acknowledged.
