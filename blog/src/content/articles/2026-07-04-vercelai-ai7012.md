# Vercel AI SDK 7.0.12: Bug Fixes for Tool Integration and JSON Streaming

Vercel has released version 7.0.12 of its AI SDK, a maintenance update addressing two specific issues that impact how AI applications handle tool execution and JSON data streaming. While modest in scope, these fixes target important workflow scenarios for developers building AI-powered applications.

## TL;DR

- **Tool result ordering**: The SDK now correctly sequences tool execution results to match the order in which tools were originally called, preventing logic errors in multi-tool scenarios
- **JSON streaming cleanup**: Fixed a whitespace preservation bug in JSON markdown fence handling that could corrupt streamed text data
- **Impact**: Developers using complex tool chains or JSON-based AI responses will see more reliable behavior, particularly in streaming contexts

## Background

The Vercel AI SDK serves as a bridge between JavaScript/TypeScript applications and large language models, providing unified APIs for model interactions, streaming, and structured output handling. As the SDK has matured, maintaining correct behavior around edge cases becomes increasingly important.

Tool calling—where AI models invoke external functions or services—represents a key capability for building agentic AI applications. When models call multiple tools in sequence, the order in which results are presented back to the model affects reasoning quality and action sequencing. Similarly, JSON extraction from model outputs often involves parsing markdown-fenced code blocks, and whitespace handling in streaming contexts can cause subtle corruption of the final output.

These issues emerged from real-world usage patterns where developers integrate multiple tools or rely heavily on structured JSON responses from streaming endpoints.

## How it works

### Tool Result Ordering in Generation Output

When an AI model generates a response that includes multiple tool calls, the SDK must convert this generation output into a structured response message. Previously, tool results could be returned in an arbitrary order rather than the sequence in which the model originally called them.

This matters significantly in agentic workflows. Consider an application where a model first calls a database query tool, then uses those results to call a calculation tool, then a formatting tool. If the SDK returns results out of order, the model's context becomes misaligned with the actual execution sequence, potentially causing incorrect decisions or repeated tool calls.

The fix sorts tool results by their tool call order when converting generation output. This ensures the response message maintains causal consistency—each tool result appears in the position corresponding to when the tool was invoked. For developers, this means more predictable behavior when building chains of dependent tool calls, particularly in scenarios with three or more sequential tools.

### JSON Extraction and Markdown Fence Whitespace

JSON extraction from model outputs frequently involves extracting content between markdown code fence markers (```json and ```). The `extractJsonMiddleware` processes streaming text, identifying and removing these fence markers while extracting the JSON content between them.

A bug existed in how the middleware handled whitespace when no markdown fence prefix was stripped but content was being prepared for final output. During streaming, text arrives incrementally, and the middleware needs to buffer and process this data correctly. When the final text suffix was streamed, the middleware could preserve leading whitespace that should have been normalized or removed during fence processing.

This caused issues where JSON responses would include unexpected whitespace at the beginning of fields or values, creating parsing errors or subtle data corruption in downstream JSON processing. The fix ensures that leading whitespace is properly handled regardless of whether markdown fence prefixes were stripped, maintaining clean JSON output throughout the streaming lifecycle.

Both dependency updates (AI SDK Gateway 4.0.9 and Provider Utils 5.0.4) likely include complementary fixes or performance improvements supporting these core changes.

## What happens next

Developers using the Vercel AI SDK should evaluate whether these fixes address issues in their applications. The tool ordering fix particularly benefits applications using multi-step tool chains, while the JSON whitespace fix helps streaming JSON implementations. Upgrading to 7.0.12 is straightforward through npm or yarn package managers.

The fixes represent the SDK's continued maturation toward production-grade reliability, though they don't introduce new capabilities—focus remains on correctness and stability.
