## How it Works

### The Role of AI Gateway in the SDK Architecture

The AI Gateway serves as an abstraction layer that decouples application code from provider-specific implementation details. When you call a language model through the Vercel SDK, your request doesn't go directly to OpenAI, Claude, or Gemini. Instead, it routes through the gateway, which handles the translation layer.

This architecture provides several practical benefits. First, it simplifies provider switching—if you decide to migrate from one model to another, your application code remains largely unchanged. Second, it enables unified monitoring and logging across all your AI API calls, regardless of which provider you're using. Third, it can implement cross-cutting concerns like request queuing, timeout handling, and error recovery without duplicating this logic for each provider integration.
