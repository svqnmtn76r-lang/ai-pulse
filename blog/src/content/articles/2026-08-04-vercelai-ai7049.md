## How it works

### Understanding the Gateway Architecture

The @ai-sdk/gateway package serves as a critical intermediary between applications built with Vercel's AI SDK and the actual AI model APIs. Think of it as a translation layer: your application code speaks the standardized Vercel AI language, while the gateway converts those requests into the specific format each provider expects.

This architecture provides several advantages. First, developers write integration code once and can swap between providers with minimal changes. Second, the gateway can implement cross-cutting concerns like rate limiting, logging, and caching at a centralized point rather than duplicating this logic across applications. Third, as providers update their APIs, Vercel can handle the compatibility work in the gateway rather than requiring every developer to update their code.
